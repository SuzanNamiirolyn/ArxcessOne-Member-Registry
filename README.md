# ArxcessOne-Member-Registry
A lightweight full-stack module to register, search and manage members. Built with React 19 + TypeScript + Tailwind CSS + Shadcn/ui, Quarkus Java API and MySQL. Features member creation, filtering, status tracking and live stats. Containerized, deployed via CI/CD behind Nginx with HTTPS. Reusable ArxcessOne component, built to production standards.
